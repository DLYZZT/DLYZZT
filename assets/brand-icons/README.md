# Brand SVG icons

These brand marks come from [Devicon](https://github.com/devicons/devicon), a community-maintained collection of technology logos. Devicon is distributed under the MIT license; see [LICENSE](LICENSE). Brand names and trademarks belong to their respective owners.

Original files: `icons/<name>/<name>-original.svg` for `typescript`, `python`, `rust`, `react`, `electron`, and `cloudflare` in the Devicon repository.

The source SVGs are stored locally and embedded as vector paths in the two technology-stack cards; no external image service is needed. The monochrome Rust mark follows the card's text color for readability on both themes.

Rebuild both cards with `python3 scripts/build-stack.py` from the repository root.
